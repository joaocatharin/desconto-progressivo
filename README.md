# Desconto Progressivo 🏷️

Um programa simples e eficiente desenvolvido em **Python** para cálculo automatizado de descontos progressivos em compras online ou presenciais.

---

## 📌 Sobre o Projeto

O desconto progressivo é uma estratégia comercial onde o percentual de desconto aumenta à medida que o valor total das compras do cliente atinge determinadas faixas. 

Este projeto recebe o valor total bruto digitado pelo usuário, aplica a regra de negócio correspondente e retorna o valor economizado e o total final a ser pago.

---

## 📏 Regras de Desconto

As faixas de desconto são calculadas da seguinte forma:

| Faixa de Valor (R$) | Percentual de Desconto |
| :--- | :---: |
| Menor que **R$ 200,00** | **5%** |
| De **R$ 200,00** a **R$ 299,99** | **10%** |
| A partir de **R$ 300,00** | **15%** |
